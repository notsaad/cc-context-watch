# cc-context-watch

A persistent context usage indicator for Claude Code.

## Overview

cc-context-watch displays a visual progress bar showing your current context window usage percentage directly in Claude Code, positioned near the message input area. This helps you monitor how much of your available context is being consumed during a session.

## Features

- Real-time context usage percentage display
- Visual progress bar indicator
- Persistent display while using Claude Code
